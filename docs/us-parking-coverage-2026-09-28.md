# US parking catalog — 28 September 2026

Bay's US map uses OpenStreetMap parking records from the [Geofabrik United States state extracts](https://download.geofabrik.de/north-america/us.html) and the [American Oceania extract](https://download.geofabrik.de/australia-oceania/american-oceania.html). It covers all 50 states, Washington DC, Puerto Rico, the US Virgin Islands, Guam, American Samoa and the Northern Mariana Islands at the source-extract level. This is a map of **places that contributors have mapped**, not a complete inventory of every physical space.

The validated snapshot contains 1,530,539 records in 54 state/territory source extracts and 36,292 compressed tiles. Of these, 112,285 are individually mapped spaces and 1,418,254 are area/zone features; 52,209 of the latter describe street-parking zones. State-extract boundaries can duplicate the same OSM object; the app removes repeated IDs in a nearby search. The counts must not be described as available spaces or distinct parking facilities.

The importer retains the downloaded PBFs locally under `datasets/us/raw-pbf/`. These large upstream extracts are intentionally excluded from Git; each state manifest records its source URL, byte count and SHA-256 checksum. Git tracks the filtered parking-only source archive (`datasets/us/YYYY-MM-DD/*-parking-osm.jsonl.gz`), the normalized, compressed map tiles (`public/data/usa/`) and the coverage audit. `datasets/manifest.json` lists the tracked files and checksums. The archived tags and geometry support rebuilding without guessing missing attributes. [OpenStreetMap contributors and ODbL](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines) are credited in the app and data index.

An `amenity=parking` feature is displayed as a parking area; a separately mapped `amenity=parking_space` feature may be shown as a space. Individually mapped spaces inside an area are counted in that area's details, rather than rendered as a misleading wall of markers. Streets with parking tags are shown as **mapped street parking**, not surveyed bays. Explicitly private, prohibited and permit-only records are excluded. Records without published entry conditions remain labelled accordingly.

The OSM extracts do **not** publish current occupancy for a nationwide sensor network. Bay therefore does not colour US parking as vacant or occupied, turn capacity into vacancy, or infer a price from the `fee` tag. An explicit `charge` tag is shown as a mapped charge with a current-price caveat; an exact operator tariff requires a separately verified source. Entrances, signs, opening hours and prices can change after an OSM edit. A source edit date is not a live observation.

To rebuild: install `scripts/data-requirements.txt`, run `python3 scripts/build_us_parking.py --all`, then `python3 scripts/verify_us_parking.py --require-all` and `python3 scripts/finalize_us_manifest.py`. State updates can use `--state STATE`, and an interrupted import can resume with `--missing`. The browser fetches only nearby 0.1° gzip tiles; these are decompressed locally to keep the public site small. The map base uses [OpenStreetMap's public tile endpoint](https://operations.osmfoundation.org/policies/tiles/), which should be replaced by a production-scale map provider before broad US promotion. Location text search runs only after an explicit user action to respect [Nominatim's public service policy](https://operations.osmfoundation.org/policies/nominatim/).

Coverage counts, validation and deployment commit are recorded in [PROJECT_TRACKER.md](PROJECT_TRACKER.md).
